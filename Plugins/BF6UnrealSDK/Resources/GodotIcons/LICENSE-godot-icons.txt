The icons in this folder named after Godot node types (Node.svg, Node3D.svg,
MeshInstance3D.svg, Camera3D.svg, Marker3D.svg, Area3D.svg, Path3D.svg,
CollisionShape3D.svg, CollisionPolygon3D.svg, PackedScene.svg, Skeleton3D.svg)
are taken unmodified from the Godot Engine editor icon set and are used here so
the outliner shows the same symbols creators see in the Portal SDK.
