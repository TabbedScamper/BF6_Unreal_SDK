# Extended block sources

The extended block definitions are maintained with the SDK. They target generated TypeScript and require the matching project target; native Portal blocks remain a separate export target.

The underlying Blockly and converter sources keep their original license notices. Template exports support the [Mike DeLuca scripting template](https://github.com/deluca-mike/bf6-portal-scripting-template) and [Portal bundler](https://github.com/deluca-mike/bf6-portal-bundler).
